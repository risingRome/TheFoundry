# Operations Dashboard MVP Architecture

## Folder Structure

```text
src/OpsDashboard.Domain
  Entities: Team, Agent, CaseType, OperationsCase, AuditLog, DataFreshness
  Enums: CaseStatus

src/OpsDashboard.Application
  Abstractions: IOpsDashboardDbContext, IDashboardService
  Dashboards: DashboardService, ExecutiveDashboardDto, TeamDashboardDto, AgentDashboardDto
  Kpis: KpiCardDto, KpiThresholds, KpiStatus

src/OpsDashboard.Infrastructure
  Data: OpsDashboardDbContext, SeedData
  Identity: ApplicationUser, AppRoles
  Migrations: EF migration target folder

src/OpsDashboard.Web
  Controllers: DashboardController, DashboardApiController, CasesApiController
  Views/Dashboard: Executive, Team, Agent
  wwwroot: Bootstrap-compatible CSS and Chart.js helpers
```

## Database Schema

Core domain tables:

- `Teams`: operational team master data.
- `Agents`: agent master data, optionally linked to an Identity user.
- `CaseTypes`: SLA lookup table with configurable threshold hours.
- `OperationsCases`: source case facts used for TAT, SLA, productivity, backlog, and FCR.
- `DataFreshness`: last refresh/status metadata.
- `AuditLogs`: append-oriented audit trail with hash-chain columns.
- ASP.NET Core Identity tables: generated by EF Core for users, roles, claims, and login state.

Key indexes:

- `UX_OperationsCases_SourceCaseId` for idempotent ingestion.
- `IX_OperationsCases_Team_CreatedAt` for team dashboards.
- `IX_OperationsCases_Agent_ResolvedAt` for agent productivity.

## KPI Calculations

- Average TAT: average `(ResolvedAtUtc - CreatedAtUtc).TotalHours` for resolved cases.
- SLA Breach Rate: resolved cases where TAT exceeds `CaseType.SlaThresholdHours` divided by resolved cases.
- Productivity: cases closed divided by working days in the selected period.
- Backlog Volume: cases created by the selected date that are still open or resolved after the selected date.
- FCR: resolved cases without escalation and without reopen divided by resolved cases.

Thresholds follow the report:

- Avg TAT: green `< 20h`, amber `20-24h`, red `> 24h`.
- SLA Breach Rate: green `< 5%`, amber `5-10%`, red `> 10%`.
- Productivity: green `>= 45`, amber `35-45`, red `< 35`.
- FCR: green `>= 80%`, amber `65-80%`, red `< 65%`.

## Roles

- Admin: full cross-team access and ingestion rights.
- Analyst: cross-team aggregated access and ingestion rights.
- Team Lead: own team dashboards and agent drill-down.
- Agent: personal metrics.
- Viewer: own team summary.

## API Endpoints

MVC pages:

- `GET /Dashboard/Executive`
- `GET /Dashboard/Team/{id?}`
- `GET /Dashboard/Agent/{id?}`

JSON dashboards:

- `GET /api/v1/dashboard/executive?from=2026-05-01&to=2026-05-31`
- `GET /api/v1/dashboard/teams/{teamId}?from=2026-05-01&to=2026-05-31`
- `GET /api/v1/dashboard/agents/{agentId}?from=2026-05-01&to=2026-05-31`

Case ingestion:

- `POST /api/v1/cases`
- `GET /api/v1/cases/{id}`

Sample case payload:

```json
{
  "sourceCaseId": "CRM-12345",
  "teamId": 1,
  "agentId": 1,
  "caseTypeId": 1,
  "createdAtUtc": "2026-06-01T08:00:00Z",
  "resolvedAtUtc": "2026-06-01T18:00:00Z",
  "escalated": false,
  "reopened": false
}
```

## C# Class Map

- `OperationsCase`: fact table record for each operational case.
- `CaseType`: SLA threshold lookup.
- `DashboardService`: central KPI calculation service used by MVC and API.
- `KpiThresholds`: report threshold mapping.
- `ApplicationUser`: Identity user extended with team and agent scope.
- `SeedData`: role, user, lookup, and sample data bootstrapper.
