SECTION 5
Core KPI Definitions & Thresholds
Turnaround Time (TAT)
Hours from case creation to resolution. Formula: (resolved_at - created_at).total_seconds() / 3600.
Report as mean, median, and P90 per team per month.
SLA Breach Rate
Percentage of cases where TAT exceeds the configured threshold. Default: 24h. Parameterisable per
case type via a lookup table. Breached = TAT > SLA_THRESHOLD.
Productivity (cases/day)
Cases closed by agent / working days in period. Identifies both high performers and capacity gaps for
staffing decisions.
Backlog Volume
Cumulative (cases opened − cases resolved) as of a date. A rising backlog signals demand exceeding
throughput. Forecasted with a rolling 7-day projection.
SLA Aging Buckets
Distribution of open cases by age: 0–4h, 4–12h, 12–24h, 24h+. Used to prioritise intervention before a
case breaches SLA.
First Contact Resolution (FCR)
Cases resolved without escalation or re-open. FCR = resolved_without_escalation / total_cases. Target:
≥ 80%.
Re-open Rate
Cases closed and later re-opened, as a percentage of total closures. A proxy for resolution quality.
Target: < 3%.
Cost per Case
Optional financial overlay. Total operational cost / total cases resolved. Enables headcount efficiency
analysis for Finance stakeholders.

6.1 Unified Ingestion Gateway
All six ingestion paths converge on a single process_and_load() function — the system's validation and
transformation gatekeeper. Any schema change or new KPI added here applies instantly to every
source.
REQUIRED_COLS = ['case_id','agent_id','team','created_at','resolved_at']
SLA_THRESHOLD = 24 # hours — overridden per case_type via lookup table
 
def process_and_load(df, source, mode='append'):
# 1. Schema contract
missing = [c for c in REQUIRED_COLS if c not in df.columns]
if missing: raise ValueError(f'Missing: {missing}')
# 2. Type coercion
df['created_at'] = pd.to_datetime(df.created_at, utc=True)
df['resolved_at'] = pd.to_datetime(df.resolved_at, utc=True)
# 3. KPI computation
df['tat_hours'] = (df.resolved_at-df.created_at).dt.total_seconds()/3600
threshold = df['case_type'].map(SLA_LOOKUP).fillna(SLA_THRESHOLD)
df['sla_breached'] = df['tat_hours'] > threshold
df['month'] = df.created_at.dt.to_period('M').astype(str)
# 4. PII masking — Silver zone only
df['agent_id'] = pseudonymise(df['agent_id'])
# 5. Audit stamp
df['source'] = source
df['ingested_at'] = datetime.utcnow().isoformat()
write_to_warehouse(df, mode)
log_audit_event(source, len(df), current_user())
6.2 KPI Aggregation — Pandas vs Warehouse SQL
For small-to-mid scale, Pandas aggregations run in-pipeline. At enterprise scale, these are replaced by
dbt models and materialized views in the warehouse — avoiding memory pressure and keeping
transformation logic version-controlled.

6.3 Data Quality Contracts
Great Expectations or Pandera enforce schema contracts before any KPI is computed. A failed check
halts the pipeline and triggers an alert — preventing corrupt data from reaching the Gold zone.
import pandera as pa
 
schema = pa.DataFrameSchema({
'case_id': pa.Column(str, nullable=False, unique=True),
'tat_hours': pa.Column(float, pa.Check.ge(0), nullable=False),
'team': pa.Column(str, pa.Check.isin(['Alpha','Beta','Gamma'])),
'created_at': pa.Column('datetime64[ns, UTC]', nullable=False),
})
schema.validate(df) # raises SchemaError if contract violated

6.4 Data Freshness Indicator
Every Gold-zone table carries a freshness metadata row. Tableau reads this to display a 'Last Updated'

def update_freshness(table_name, row_count, status='success'):
engine.execute("""
INSERT INTO ops_meta.freshness
(table_name, refreshed_at, row_count, status)
VALUES (:tn, NOW(), :rc, :st)
ON CONFLICT (table_name) DO UPDATE SET
refreshed_at=NOW(), row_count=:rc, status=:st
""", tn=table_name, rc=row_count, st=status)

SECTION 8
Data Ingestion Methods
Six ingestion pathways are supported. All converge on process_and_load() — ensuring consistent
validation, KPI computation, and audit logging regardless of source.
1 CSV / Excel File Upload
 pandas.read_csv() or read_excel() with parse_dates and dtype specification.
 Three write modes: append (incremental), replace (daily full refresh), upsert by case_id.
 Validate encoding (UTF-8), max file size (50 MB), and column presence before processing.
 Returns row count, error count, and computed TAT range as ingest summary.
2 Manual Form Entry
 FastAPI + Pydantic v2 model — automatic type coercion and enum validation.
 TAT computed server-side; client-submitted values are ignored.
 Streamlit or Retool provides a no-code form UI for operations staff.
 INSERT ... ON CONFLICT DO UPDATE ensures idempotent case submission.
3 REST API — Programmatic Push
 JWT-authenticated POST /api/v1/cases with role check (admin or operator only).
 Batch endpoint POST /api/v1/cases/batch accepts up to 10,000 cases per request.
 Rate-limited with slowapi — 1,000 req/min per API key.
 201 response returns computed TAT, SLA flag, and case_id confirmation.
4 Database-to-Database Sync
 SQLAlchemy reads source with incremental filter on updated_at timestamp.
 Scheduled as Airflow PythonOperator — configurable to hourly, daily, or ad-hoc.
 For CDC: Debezium + Kafka logical replication — zero-latency, no polling.
 Replace Pandas with Polars or PySpark at >5M rows/day source volume.
5 Real-Time Kafka Stream
 KafkaConsumer on ops.cases.resolved — processes each event within 60 seconds.
 Triggers immediate upsert and SLA breach alert check per event.
 Runs as long-lived sidecar alongside the batch Airflow pipeline.
 AWS-native: Kinesis stream + Lambda function. Azure: Event Hub + Azure Function.
6 Bulk / Webhook / Background
 Google Sheets: gspread library reads named tab on nightly Airflow schedule.
 Inbound webhook: HMAC-SHA256 signature validation before any data is accepted.
 Email parser: imaplib monitors mailbox for CSV attachments and auto-ingests.
 S3 folder watch: S3 Event Notification triggers Lambda on new Parquet arrival.

9.2 Encryption
 At rest: AES-256 server-side encryption on all S3/GCS buckets via AWS KMS or GCP Cloud KMS.
 In transit: TLS 1.3 enforced on all DB connections, API endpoints, and Tableau live connections.
 Key rotation: annual rotation for storage keys; 90-day rotation for database credentials.

9.4 Audit Logging — Tamper-Evident
 Append-only audit_log table — DB role has INSERT privilege only, no UPDATE/DELETE.
 HMAC hash chain: each row includes HMAC of previous row's hash — detects tampering.
 Every query, export, login, and schema change is logged with user_id, IP, and timestamp.
 Audit logs retained 10 years in a separate, tightly access-controlled schema.
9.5 Network Security
 All services deployed inside a VPC — no direct public internet exposure.
 Inbound allowed only from whitelisted CIDR ranges (office IPs, Tableau Server).
 Human DB access via AWS SSM Session Manager / bastion host only.
 MFA enforced for all dashboard users via Okta or Azure Active Directory (SSO).
 VPC Flow Logs and AWS GuardDuty enabled for anomalous traffic detection.

SECTION 16
Deployment Tiers by Organisation Size
The architecture is designed to scale incrementally. Teams start with Tier 1 and migrate upward as
volume and complexity grow — no big-bang rewrite required.
Tier 1 — Small Organisation
< 2,000 cases/day | < 20 users | 1–3 teams
 PostgreSQL as both operational and analytics database.
 Pandas pipelines run as scheduled Python scripts (cron or simple Airflow).
 MinIO for local S3-compatible object storage — zero cloud cost.
 Tableau Desktop connected directly to PostgreSQL.
 CSV and manual form entry as primary ingestion methods.
 Estimated infrastructure cost: < $200/month.
Tier 2 — Mid-Size Organisation
2,000–50,000 cases/day | 20–200 users | Multiple teams
 Snowflake or BigQuery as the cloud data warehouse.
 Apache Airflow on managed cloud (Astronomer or AWS MWAA).
 dbt for SQL-based KPI transformations and lineage.
 CSV, REST API, and database sync ingestion methods active.
 Tableau Server published with row-level security and scheduled refresh.
 Estimated infrastructure cost: $500–$2,500/month.
Tier 3 — Enterprise
> 50,000 cases/day | 200+ users | Cross-department
 Kafka + Debezium for real-time CDC from all source systems.
 Apache Spark or Polars for high-volume Silver zone transformations.
 ClickHouse for sub-second real-time KPI aggregations.
 Full OpenLineage data lineage tracking across all transformations.
 Tableau Cloud with SSO, MFA, and centralised governance.
 Multi-region active/passive DR with Snowflake failover.
 Estimated infrastructure cost: $3,000–$15,000+/month.
